Social Network Graph Project

This project simulates a social network using graph data structures and algorithms. In this system, users are represented as nodes and friendships are represented as connections (edges) between them.

The application allows dynamic addition of users and connections, enabling the network to grow interactively. It provides features such as finding mutual friends, suggesting new connections based on shared relationships, and identifying the shortest connection path between users.

The project is designed with a simple interactive user interface and a backend implemented using Node.js. Core graph operations like traversal and shortest path are handled efficiently using algorithms such as Breadth-First Search (BFS).

Features

* Add users and create connections
* View complete network of users
* Find mutual friends between users
* Get friend recommendations based on mutual connections
* Find shortest path between two users

Tech Stack

* JavaScript (Node.js)
* HTML, CSS
* Graph Data Structure (Adjacency List)

How to Run

1. Install dependencies:
    npm install
2. Start the server:
    node server.js
3. Open in browser:
    http://localhost:3000
